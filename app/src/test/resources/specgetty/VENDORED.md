# Vendored corpus

specgetty's own `openspec/` tree, copied verbatim from
https://github.com/speclib/specgetty. MIT, and by the same author as this
project.

`BRIEFING.md` names it as the definition of done: the parsers are tested against
specgetty's fixtures *and* against real specs and changes from the specgetty
repo itself, which tracks its own work in OpenSpec. This is that repo's work.

It is test data only. It lives under `app/src/test/resources/` and is not
packaged into the APK.
