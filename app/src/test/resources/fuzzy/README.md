An oracle for the fuzzy matcher.

`cases.tsv` holds one case per line: a pattern, then the candidates, tab
separated. The candidates are the real change and capability names of the
vendored specgetty project, plus synthetic cases for each scoring rule.

`expected.txt` is what `github.com/sahilm/fuzzy` v0.1.3 returns for those cases,
generated by running the library itself. specgetty ranks with that library, so
matching it exactly is what keeps the two tools agreeing about a search.

Regenerate by feeding `cases.tsv` to a Go program calling `fuzzy.Find` and
printing `pattern -> name=score name=score ...` in the order returned.
