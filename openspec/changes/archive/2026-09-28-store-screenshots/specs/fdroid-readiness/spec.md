## MODIFIED Requirements

### Requirement: The store listing exists and does not overstate

The project SHALL provide Fastlane metadata for the default locale, and every
screenshot it ships SHALL have been taken from the running app rather than
composed by hand.

#### Scenario: The metadata

- **WHEN** `fastlane/metadata/android/en-US/` is read
- **THEN** it holds a title, a short description, a full description and a
  changelog for version 1

#### Scenario: Screenshots

- **WHEN** the screenshots directory is read
- **THEN** it holds images taken by driving the app on an emulator

#### Scenario: Taking them again

- **WHEN** the app's appearance changes
- **THEN** the screenshots can be regenerated by one command rather than redrawn

#### Scenario: What is photographed

- **WHEN** a screenshot is taken
- **THEN** the project in it was written by the test, not taken from somebody's
  repository

#### Scenario: What the description claims

- **WHEN** the full description is read
- **THEN** it says this version reads and does not edit
